# Woosh Studio 0.2.2 修复与验收

日期：2026-09-12。针对配音停在“复用”、音效资源混排、批次/版本展示、Flow 配套安装和音乐性能/破音的修复。

## 已实现

- 配音改为完整文本分句合成，按句长限制音频 token 数，并上报实际帧进度和耗时。超过 15 秒的参考录音采用前 10 秒提取声线，避免长参考上下文续说；原参考文件保留。
- 音效面板只显示音效及关联处理版本。每个批次内原始版本、变体和裁剪版本共用卡片；追加变体延续关联，递增种子继续前进。
- 新音效根据提示词生成名称，可手动覆盖。旧版缺少批次 ID 的资料优先从历史任务恢复；无法恢复的只在展示层按编号和相近时间归档，并明确标记历史批次，不伪造来源关系。
- 波形来自实际采样最小/最大值，频谱图来自窗口化 FFT，支持立体声反相信号。原来的固定装饰波形已移除。
- 音乐缓存长度根据实际提示词和时长分配，显存分配按可用空间调整；启用 TF32，并增加 10 秒快速预览。标准模式保留 10 步声码器解码；默认不额外分轨。
- 音乐生成写入 PCM24 前执行线性峰值保护，不用硬截断音频。已有超满幅音乐可以生成独立保护版本。电子风格标签会明确提示，并提供管弦/原声切换。
- Flow 与 DFlow 的真实权重均已在共享模型库验证，新离线包包含两者以及 Woosh-AE、TextConditionerA、Whisper 和离线运行环境。

## 本机真实验证

设备：RTX 4060 Ti 8 GB。下列耗时是本次样本实测，不能作为所有提示词或设备的速度保证。

| 项目 | 结果 |
| --- | --- |
| 用户问题台词、原参考录音 | 旧版在 150 秒保护截止时仍未自然结束；修复版约 34.1 秒完成，生成 10.36 秒音频 |
| 配音内容复核 | 真实 Whisper 复核的归一化文本与该英文台词一致 |
| 10 秒音乐目标旧版对照 | 5 分钟内仍未完成，约生成至 2 秒内容后停止对照 |
| 新版 10 秒快速预览 | 约 80.3 秒完成，包含约 24.1 秒首次加载；此模式使用较少解码步骤和 CFG=1 |
| 新版 30 秒标准音乐 | 约 223.6 秒完成，包含约 27.3 秒首次加载；仍然是分钟级生成 |
| 原有超满幅音乐 | 原始峰值 1.5573，独立保护版本峰值 0.98，线性衰减约 4.02 dB |
| Flow / DFlow | 两个真实模型均完成生成、自动命名及批次资产登记 |

峰值保护处理的是可测量的超满幅问题，不能保证消除模型本身生成的所有电子质感或杂音；仍需试听并选择合适风格与版本。
