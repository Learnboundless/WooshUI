# Woosh Studio 功能工作流

## 项目和素材

新建或打开 `.woosh` 项目，记录本机项目根目录。项目清单是 `project.woosh.json`；素材在 `Sources`、生成结果在 `Generated`、预览在 `Renders`、交付在 `Exports`。修改项目先读取最新清单，保留未知于当前工作流但合法的既有内容。

剧本工作台可拖入文件或整个文件夹，也可选择文件/文件夹。支持 WAV、FLAC、MP3、OGG、AIFF、JSON、TXT、MD。单次最多 200 个文件、1 GB；单音频最多 200 MB、单模板 2 MB。只复制支持的真实文件，查看导入报告；不自动执行任何文件。角色参考音频可从项目素材选择，也可拖入单个音频到参考区域直接绑定。

## 音效

1. 提供名称、分类、中文原意与具体英文声音描述；按物体、动作、环境、距离和质感描述。界面可调用本地翻译模型协助。
2. 检查 Woosh-DFlow 或 Woosh-Flow 是否已安装。count 为 1–8，可选择随机、固定或递增 seed。
3. 先生成一个变体并试听，再调整描述、CFG 或变体数。音效模型的输出长度由模型决定，不承诺不存在的可变时长输入。
4. 对音头尾静音使用自动去静音；需要准确范围时用手动裁剪。保留原素材和新的处理结果。

## 音乐

1. 检查 HeartMuLa-3B。选择纯音乐或带歌词；纯音乐 lyrics 为空，歌曲必须提供歌词，可使用 [Intro]、[Verse]、[Chorus]、[Bridge]、[Outro]。
2. tags 是英文风格标签，最多 24 个。时长选 30、60、120 或 240 秒，变体数 1–4。
3. 需要分轨时检查 Demucs-htdemucs 并开启分轨。生成后分别试听混音和 vocals/drums/bass/other；Demucs 是分离结果，不声称它是原生作曲分轨。
4. 把所需音轨添加到工作台，对混音或分轨调整音量与剪辑。

## 角色配音

1. 使用「剧本提示词」生成脚本或「角色提示词」生成音色模板；导入前检查预览和追加/替换方式。
2. 内置音色用 Qwen3-TTS-CustomVoice-1.7B；参考音频克隆用 Qwen3-TTS-Base-1.7B。克隆需要参考文件及准确转录。当前 Base 克隆流程从参考录音获取声线和语气，不应用文字 instruct；文字表演指导用于 CustomVoice，克隆角色的文字指导仅作为创作备注保存。
3. 在角色列表选中角色，设置默认语言和语气。改变角色语言会同步绑定台词的目标语言，并用本地翻译生成译文，保留原文。中译英优先使用已有 opus-mt-zh-en；其他方向使用随应用内置的多语种对白翻译 m2m100-418M-int8，首次启动自动准备，用户无需下载或复制权重。切换模型目录后应用自动从安装目录的本地压缩包部署；如果内置包缺失或损坏，使用完整安装包修复应用。拉丁字母语言自动识别默认英文，非英语原文请明确选择原文语言。译文可在生成前人工修订。台词的 voice_id 必须绑定存在的角色；可以单独调整本句语言和情绪。
4. 先生成单句试听，再生成所有启用台词。停用的台词不参与生成；空台词、缺少音色/参考/模型会阻止提交。
5. 可搜索角色/台词、筛选待处理项、上移下移或删除台词。剧本自动保存，Ctrl+S 可立即保存；保存失败需重试。生成完成后在台词下方直接试听、定位文件或复制完整路径；修改台词后保留历史配音入口，并标明旧版本。缺失文件会显示明确标记，可重新关联真实文件，或从项目移除素材和关联片段（磁盘源文件保留）。

## 音频处理和工作台

对素材进行手动裁剪或自动去静音。手动裁剪要满足 0 <= start < end <= 原素材时长。默认去静音阈值 -45 dB，前后保留 0.04 秒，可在真实 API schema 范围内调整。

把素材加入轨道，设置片段的 start_seconds、trim_start_seconds、trim_end_seconds、淡入淡出、gain_db、pan、循环和效果链。轨道支持静音、独奏和音量；效果包括 pitch、speed、eq、compressor、reverb、limiter、normalize。先读取现有 timeline，保留轨道和素材关联，只修改与用户要求相关的项。参数名和范围查当前 `/api/openapi.json` 及应用实际提供的控件，不凭印象创造效果参数。

渲染预览后试听衔接、音量和长度。所有 source_path 指向实际存在的项目音频，相对路径不能越出项目目录。

## 模型和运行设置

读取模型清单和设备能力。按需安装音效、音乐、语音、翻译或分轨模型；自定义本机模型用注册接口。需要接受模型许可时展示实际许可，由用户作出许可决定。不要假定另一台电脑具有 CUDA、相同显存或相同模型根目录。

设置页可选择设备、模型根目录、下载源、音乐内存模式、语言和主题。修改设置应读取完整现有 settings 后合并所需字段。下载、模型路径迁移或删除按用户授权范围执行；不要为了生成音频删除无关模型。离线电脑使用应用的离线安装包和本地权重，不把 skill 当作模型安装包。

## 队列和导出

记录生成、模型下载、分轨和导出返回的任务 ID。轮询 `/jobs/{id}`，只在 completed 后使用结果；failed/cancelled/interrupted 需报告。点击任务卡片可查看失败阶段、原始错误和任务参数，并复制诊断；历史记录在重启后保留。音乐混音生成成功而后续分轨失败时，混音素材仍保留，可单独重试分轨。暂停/恢复主要用于应用支持暂停的模型下载任务；不假定所有推理都能暂停。

导出 WAV24、WAV16、FLAC 或 OGG；选择独立文件或 Wwise/FMOD 资源包。命名模板默认 `{category}_{name}_{variant:02}`。核对选择的资产、实际目标路径、文件数量、格式和可播放性。保留源项目和清单，方便另一台电脑继续编辑。
